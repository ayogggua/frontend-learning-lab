这里的 HTML、CSS、JS 怎样连起来？
真实项目由 HTML 的 link 和 script 引入文件。本实验把编辑器里的 CSS 和 JS 注入独立 iframe，保留真实浏览器执行，方便离线练习。HTML 面板编辑 body 内容，JS 放在 body 节点之后执行；本实验不模拟外部文件下载耗时。
<!doctype html>
<html lang="zh-CN">
  <head>
    <meta charset="utf-8">
    <link rel="stylesheet" href="./style.css">
    <script src="./app.js" defer></script>
  </head>
  <body>…页面结构…</body>
</html>
第一次绘制与 defer 执行没有固定先后。defer 的关键保证是：文档解析后、DOMContentLoaded 前执行。
